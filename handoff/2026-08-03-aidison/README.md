## 事实来源优先级

发生冲突时按以下顺序判断：

1. 当前运行代码、配置、迁移和已执行测试；
2. 用户已经确认的产品定义与边界；
3. `CONTEXT.md` 的领域语言与不变量；
4. accepted ADR；
5. `docs/ARCHITECTURE.md` 与 `docs/STATUS.md`；
6. 本交接包；
7. 开发前研究报告和历史比较文档。

研究文档记录的是形成方案时的证据与推演，其中的 `not started`、`待实施` 或旧基线判断可能已被后续代码和正式规格取代。不得反向用历史文档覆盖当前实现。

1. 不要运行 `git reset --hard`、`git clean` 或对整个仓库执行 checkout；大量已实现能力只存在于当前未提交现场。
2. 不要把测试连接到 `localhost:5432/aidison`。集成测试会执行 `TRUNCATE ... CASCADE`，必须使用可丢弃的 `aidison_test`。
