# Aidison 当前研究与设计文档

本目录只保留仍有实施价值的产品蓝图、技术设计、项目比较和验证标准。旧 DeerFlow 主体路线、过程状态、研究日志和重复交接已归档到工作区外。

## 推荐阅读顺序

1. `PRODUCT_VISION.md`：产品是什么，首版解决什么。
2. `DEEP_AGENTS_DEMO_FUSION_BLUEPRINT.md`：当前唯一主线，包含源码边界、FastAPI/PostgreSQL、Multi-Agent、A2A、可观测性、前端展示台和项目融合。
3. `AGENT_WORKFLOW.md` 与 `MULTI_AGENT_ORCHESTRATION.md`：LangGraph、Logical Agent、Subagent、Job/Attempt/Delegation/JoinReceipt。
4. `PRODUCT_CONSOLE.md`：Project-first 浏览器控制台。
5. `MEMORY_SYSTEM.md`：记忆、证据和业务事实的所有权边界。
6. `REFERENCE_PORTFOLIO_23.md` 与 `APPLICATION_TAXONOMY_23.md`：23 个参考对象的采用价值、场景和成熟度。
7. `projects/README.md` 与 `../aidison-new-projects-round3/COMPARATIVE_SYNTHESIS.md`：项目级研究和第三轮源码审计索引。
8. `appendices/VALIDATION_MATRIX.md` 与 `appendices/UNKNOWNS.md`：实施测试和未验证项。

## 保留产物

- `DEEP_AGENTS_DEMO_FUSION_BLUEPRINT.md`：当前总架构与 V0 边界。
- `PRODUCT_VISION.md`、`PRODUCT_CONSOLE.md`：产品与交互。
- `AGENT_WORKFLOW.md`、`MULTI_AGENT_ORCHESTRATION.md`、`MEMORY_SYSTEM.md`：核心工程设计。
- `REFERENCE_PORTFOLIO_23.md`、`APPLICATION_TAXONOMY_23.md`：跨项目总结。
- `projects/`：仍有采用或算法价值的旧项目短报告。
- `../aidison-new-projects-round3/`：8 个新项目和两个本地项目的详细源码审计。
- `appendices/VALIDATION_MATRIX.md`、`appendices/UNKNOWNS.md`：验证与风险。
- `ARTIFACT_MANIFEST.md`：当前保留清单。

所有未实际运行的能力均为 `not_checked`。
