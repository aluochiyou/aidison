# Aidison 前端场景依据

参考：[红河素材站图标库](https://honghemc.cn/app/?ver=26.3)、[视频底图：白桦林](https://honghemc.cn/app/textures.html?seed=55412&scene=birch&intro=pop)。2026-10-25 检查：图标库的实际页面可见白底卡片、像素物品图、绿色主操作；视频底图页的 HTML 描述了地形、贴图和入场动画。Firecrawl 抓取因额度不足未返回截图，因此没有把底图页的布局或动态效果当作已核实事实。

## 用于本项目的选择

- 来源素材：现有的村庄底图、Allay、工作台/书/指南针/箱子和方块纹理；具体来源见 [素材清单](public/art/mc/SOURCE.md)。史蒂夫与猪的透明前景是为本项目生成的，并非红河原图。
- 页面层次：暖色天空与村庄只出现在项目页上缘，逐渐融入石纹；实体工作区仍用不透明纸张和物品栏式边框，保证长文字可读。这是 Aidison 的实现选择，不是对参考站的像素级复刻。
- 色彩与结构：草绿表示可执行动作，橡木棕用于导航，石灰色用于运行记录；主内容优先，开发者审计在中等宽度移到下方。
- 动效：讨论按钮触发探索扫光，模块与方案按钮触发合成色扫光，模块选择触发检查色扫光；Allay 和史蒂夫/猪短暂移动。动画只作用于装饰层，不拦截点击；`prefers-reduced-motion` 时关闭。
- 适配：宽屏角色放在内容外的留白，中小屏保留目标卡片上的 Allay，不用人物遮挡表单。未证实站点人物贴图的具体授权范围，新增素材前需单独核对。
